# TaskOnward Power

**换个对话，接着做原来的任务。**

Power **0.4.8** 支持桌面 Chrome 浏览器中的 ChatGPT、Claude 和 Gemini；现在可在扩展面板中选择 **中文 / English**。语言设置会保留，只改变界面，不翻译任务原文。

[官网下载安装](https://taskonward.5188688.xyz/start) · [使用说明](docs/power-browser-assistant.md) · [隐私说明](docs/privacy.md)

## 安装与使用

1. 下载官网的 0.4.8 ZIP，解压到固定文件夹。
2. 打开 `chrome://extensions/`，开启开发者模式，点击“加载已解压的扩展程序”，选择解压文件夹。
3. 从扩展工具栏登录 TaskOnward。在面板顶部选择中文或 English。
4. 在原对话点 P 复制续聊码；到目标新对话粘贴；检查交接内容后由用户手动发送。

同一码可以接入多个目标，但续聊不是完整聊天备份，不保证附件或所有历史无损恢复。现有 0.4.7 用户可以保留旧版或手动更新；旧版包保留回滚路径。旧 0.8.x 不再公开下载。
