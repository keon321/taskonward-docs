# TaskOnward Power

**换个 AI 对话，接着做原来的任务。**

Power **0.4.7 已开放安装**，支持桌面 Chrome 浏览器中的 ChatGPT、Claude 和 Gemini。

[下载安装](https://taskonward.5188688.xyz/start) · [使用说明](docs/power-browser-assistant.md) · [隐私说明](docs/privacy.md)

## 安装

1. 从官网下载安装包并解压到固定文件夹。
2. 打开 `chrome://extensions/`，开启开发者模式，点击“加载已解压的扩展程序”，选择含 `manifest.json` 的文件夹。
3. 在扩展中登录 TaskOnward，刷新聊天网页。用户无需单独配置 MCP 或 WorkOS。

## 使用

1. 在原 AI 对话点击 Power，复制短续聊码。
2. 在目标新对话的空白输入框粘贴。同一码可用于多个目标。
3. Power 自动填入有原文依据的任务交接内容，检查后**手动发送**。

交接不是完整聊天记录备份，缺失的历史和附件不会自动补齐。新码替代旧码，已经建立的目标分支独立保留。老观察用户可保留旧版，无需覆盖；旧 0.8.x 不再公开分发。
