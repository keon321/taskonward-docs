# TaskOnward Power

**换个 AI 对话，接着做原来的任务。**

Power 正在进行跨平台观察测试，支持 ChatGPT、Claude 和 Gemini。已授权的观察用户可以继续使用现有扩展。

[官网](https://taskonward.5188688.xyz/) · [使用说明](docs/power-browser-assistant.md) · [隐私说明](docs/privacy.md)

## 使用方法

1. 在原 AI 对话点击 Power，复制短续聊码。
2. 在目标新对话的空白输入框粘贴。同一码可用于多个目标对话。
3. 扩展自动填入有原文依据的任务交接内容；检查后**由用户手动发送**。

任务交接不是完整聊天记录备份；缺失的历史内容和文件不会自动补齐。生成下一份交接码后，上一码失效，各已接续对话保留自己的后续任务现场。

**目前暂不开放新用户下载安装。** 需要先完成固定 Chrome 扩展 ID、WorkOS 登录回调及全新安装验收。已安装的观察用户不受影响。
