# Power 浏览器助手｜手动安装

Power 是 TaskOnward 的可选浏览器助手。

它只负责简化换 Chat 流程：准备续聊内容并复制到剪贴板。你再打开新 Chat，粘贴发送即可。

## 下载

[下载 TaskOnward Power 0.7.13 ZIP](../downloads/taskonward-power-0.7.13.zip)

SHA-256：

`547797479e700d26704e3bb28baa21b3548ded25defb978bce0b51c1f4289591`

## Chrome 安装

1. 下载 ZIP，并解压；
2. 打开 `chrome://extensions/`；
3. 打开开发者模式；
4. 加载已解压的扩展程序；
5. 选择解压后的文件夹；
6. 刷新 ChatGPT。

## 使用

准备换 Chat 时：

1. 点击 Power；
2. 复制续聊内容；
3. 打开新 Chat；
4. 粘贴发送；
5. 检查恢复摘要；正确则回复「确认」，不正确就直接指出需要修改的地方；
6. 回复「确认」只完成恢复确认，TaskOnward 会停住；你明确说「继续」或给出下一条任务指令后，才继续原任务。

Power 不会自动打开新 Chat，也不会自动发送消息。

## 安全提醒

不要把密码、API Key、Cookie、OAuth 令牌或续聊令牌发给别人。
