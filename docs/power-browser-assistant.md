# Power 0.4.8｜安装及中文 / English 切换

**正式版本：0.4.8**。支持桌面 Chrome 中的 ChatGPT、Claude、Gemini。

1. 从 [官网](https://taskonward.5188688.xyz/start) 下载最新 ZIP 并解压到固定目录。
2. 进入 `chrome://extensions/`，开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
3. 从浏览器工具栏打开 TaskOnward Power，登录账号。
4. 在面板顶部“界面语言”中选择“中文”或“English”。选择会保留，刷新聊天页面后悬浮 P 提示也会使用该语言。

使用方式：原聊天点 P 复制续聊码 → 新聊天空白输入框粘贴 → Power 自动填入有原文依据的交接材料 → 用户**核对后手动发送**。同一码可用于多个目标，下一份新码替换旧码。语言设置只改变界面，不翻译交接原文或续聊码。

旧 0.4.7 用户可继续使用。升级时保留旧版文件夹作备份，以新版文件替换原解压目录并重新加载扩展；不要同时加载两个相同扩展 ID 的目录。若出现故障，使用旧包回滚。
