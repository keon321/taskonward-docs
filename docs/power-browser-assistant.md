# Power｜跨平台观察版使用方法

目前支持 ChatGPT、Claude、Gemini。仅供**已授权且已安装扩展的观察用户**继续使用。

1. 在原对话点击绿色 Power。
2. 复制本次生成的短续聊码。
3. 打开目标 AI 的新对话，将输入框保持为空，按 Ctrl+V 粘贴。
4. 扩展会取回有原文依据的任务摘录并填入输入框。
5. 用户核对内容后**手动发送**。Power 不会自动发送。

同一个码可以重复用于多个目标对话；生成新的同任务交接码后，上一码失效。已建立的目标任务分支不会因为旧码失效而自动合并。

交接内容来自有界的近期记录，不保证无损恢复整个对话、附件或全部历史决定。如果原始任务信息不足，请回到原对话核对。

**目前暂不提供新用户安装包。** 因为全新 Chrome 扩展安装还需要验证固定扩展 ID 与 WorkOS 登录回调。在此之前不要从第三方下载所谓“正式版”。

无需在目标 ChatGPT、Claude 或 Gemini 单独安装 TaskOnward MCP；观察版直接由浏览器扩展取回交接。
