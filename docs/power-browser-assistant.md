# Power｜跨平台版 0.4.7 使用方法

现已开放桌面 Chrome 下载安装，支持 ChatGPT、Claude、Gemini。

## 安装

1. 访问 [官网下载安装](https://taskonward.5188688.xyz/start)，下载 Power 0.4.7 ZIP，解压到固定文件夹。
2. 在浏览器地址栏打开 `chrome://extensions/`，开启开发者模式，点击“加载已解压的扩展程序”。
3. 选择包含 `manifest.json` 的文件夹，打开扩展，登录 TaskOnward。确认已连接后刷新聊天页面。

旧观察版用户可暂时停用旧扩展后使用 0.4.7，无需卸载或删除历史数据。无需在目标 AI 侧配置 MCP，也不需要自行填写 WorkOS 登录回调。

## 接续

1. 在原对话点击 Power，复制短续聊码。
2. 打开目标平台的新对话，保持输入框为空，粘贴该码。
3. 扩展自动填入有原文依据的任务摘录，用户检查后**手动发送**。Power 不会自动发送。

同一码可重复用于多个目标，生成新的同任务码会替代旧码。已有目标分支不会合并。交接不是完整聊天备份，缺失的历史、附件或否决项无法自动还原。
