# TaskOnward Power｜隐私与交接说明

Power 不会在普通聊天中持续录制。仅在用户明确点击 Power 时，才采集生成交接所需的有界近期内容，并与当前登录的 TaskOnward 账户绑定。

短续聊码可以用于多个目标对话，直到新的同任务交接码替代。已接续目标的必要任务分支信息可能独立保留。因此**旧码失效不等于清空历史数据**。

任务交接不是完整聊天备份，也不保证取得附件或全部旧决定。用户负责检查自动填入的内容，Power 不代替用户发送。

交接正文在服务端加密并按账户隔离。请不要把短码、密码、API Key、Cookie、OAuth 令牌或私人任务内容公开在 GitHub Issue 中。
